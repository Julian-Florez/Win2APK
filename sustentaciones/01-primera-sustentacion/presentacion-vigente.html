Ejecución del CLI

Ejemplo genérico · empaquetado e instalación de Bomb Rush Cyberfunk

cd /ruta/al/proyecto/Win2APK && \
export WIN2APK_BUNDLETOOL="$PWD/tools/bundletool-all-1.18.3.jar" && \
cargo run --manifest-path cli/Cargo.toml -- \
  --engine "$PWD/winlator/app" \
  build config/mi-aplicacion.json \
  --output dist/mi-aplicacion \
  --keep-staging && \
cargo run --manifest-path cli/Cargo.toml -- \
  install dist/mi-aplicacion/bomb-rush-cyberfunk-1.0.0.apks \
  --device SERIAL_DEL_DISPOSITIVO \
  --fresh

Los errores cambiaron el diseño

Problema4,45 GiB en un solo archivo
→
ObservaciónEl empaquetado monolítico falla
→
DecisiónDividir el payload y reconstruirlo en Android
ProblemaAndroid moderno bloquea Box64
→
ObservaciónLa app queda preparando
→
DecisiónCambiar el target recuperó el arranque probado
ProblemaRutas con ID de paquete fijo
→
ObservaciónOtro identificador rompe el entorno
→
DecisiónAdaptar rutas al identificador de cada app

El cambio de target es experimental; no demuestra que se cumplan los requisitos actuales de publicación.

Compatibilidad por dispositivo

La referencia en Qualcomm no siempre se reproduce igual en Tensor/Mali.

No hay una causa única confirmada ni una solución integrada estable. El alcance se limita a las aplicaciones y dispositivos probados.
