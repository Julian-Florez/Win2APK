Backup · Arquitectura

Qué hace cada capa y dónde termina Win2APK

Trazabilidad técnica

Canalización propia

  • CLI Rust y esquema JSON v2.
  • Inventario, hashes, segmentación y staging.
  • Identidad de paquete, icono y firma.
  • Configuración Core, acceso directo y arranque.
  • Entrega, movimiento y limpieza de una copia final.
  • Perfiles gráficos y protocolo de medición.

Componentes integrados

  • Winlator: base Android y entorno de ejecución.
  • Wine: API Windows sobre servicios POSIX.
  • Box64: traducción de código x86-64 en hosts ARM64.
  • DXVK / WineD3D: traducción gráfica.
  • Mesa / Turnip / Vortek: acceso a GPU según dispositivo.
  • Android App Bundle / PAD: distribución del payload.
No se ejecuta un kernel Windows ni se recompila la aplicación a Android nativoB2

Backup · Método

Qué se considera evidencia y qué no

Contrato de medición

Criterios observables

  • Artefacto y SHA-256 identificados.
  • Instalación o modo preinstalado explícito.
  • Primer inicio y segundo inicio separados.
  • Proceso de app y proceso objetivo visibles.
  • Captura canónica T+60 clasificada.
  • CPU, memoria, temperatura y almacenamiento cuando están disponibles.
  • Logs y video conservados.

Reglas de interpretación

  • Una pantalla negra no prueba por sí sola un cierre.
  • Sin fila de instalación no significa fallo si el modo es preinstalado.
  • FPS de carga o menú no equivale a jugabilidad.
  • Un dispositivo no representa compatibilidad universal.
  • Una hipótesis causal requiere una prueba que la aísle.
  • Los CSV históricos no se reescriben para “mejorar” un resultado.

Backup · Distribución

El límite de 4.45 GiB cambió la estrategia de empaquetado

Iteración 012 → 049

Fallo inicial

Un APK único no pudo comprimir un asset de 4,782,573,186 bytes y produjo Required array size too large.

La evidencia descartó el enfoque monolítico para payloads de ese tamaño.

Resultado posterior

La CLI planificó Cuphead en asset packs y produjo:

  • AAB: 5,494,326,036 bytes.
  • APKS: 6,424,836,814 bytes.
  • Entrega observada: 815 archivos, 5.847 GB.

Backup · Dominio

Compatibilidad, traducción y distribución no son sinónimos

Conceptos clave

Distinciones

  • Wine: traduce llamadas de API Windows a servicios POSIX; no es una máquina virtual.
  • Box64: ejecuta código x86-64 de espacio de usuario sobre un host ARM64.
  • DXVK: traduce Direct3D 8-11 a Vulkan para Wine.
  • Win2APK: empaqueta y configura esas capacidades; no recompila la aplicación.

Licencias y responsabilidad

  • El prototipo integra proyectos de código abierto con licencias propias.
  • La distribución debe conservar avisos y revisar compatibilidad de licencias por componente.
  • Win2APK no concede derechos sobre aplicaciones Windows empaquetadas.
  • El usuario debe tener autorización para redistribuir el software y sus datos.
